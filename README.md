# Web portfolio

My web portfolio. Just a few projects, some screenshots and a moth.

Plain HTML and CSS, no framework or build step.

## Have a look

[owenhynes.com](https://owenhynes.com)

Or open `index.html` locally. If you'd rather use a local server:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Then visit `http://127.0.0.1:8080`.

## Changing things

The page and styles are in `index.html`, images are in `assets/`.
To host your own copy, serve those together from a static web server.

The screenshots are from the projects shown. The moth artwork isn't included under a blanket licence.
